# 한국어 학술 윤문 규칙

이 문서는 일반적인 한국어 AI 문체 제거 규칙을 학술 원고에 적용할 때 필요한 예외와 판단 기준을 정리한다. 규칙은 금칙어 목록이 아니라 문맥별 편집 기준이다.

## 안전하게 고칠 수 있는 문제

아래 항목은 의미가 보존되는 범위에서 국소적으로 고친다.

- 이중 피동과 명백한 비문: `판단되어진다` → `판단된다`
- 불필요한 전치사식 표현: `X에 있어서` → `X에서`, `X와 관련하여` → 문맥에 맞는 조사
- 가벼운 동사 직역: `논의를 가지다` → `논의하다`, `영향을 미치게 된다` → 시제와 양태를 보존한 자연스러운 서술
- 같은 문장이나 문단 안의 의미 중복과 동의어 중첩
- 불필요하게 긴 명사화 사슬과 조사 중첩
- 연결어미 바로 뒤의 불필요한 쉼표 등 명백한 문장부호 오류
- 실제 논리 관계 없이 반복되는 `또한`, `나아가`, `한편` 등 문단 표지
- 근거 없이 평가만 반복하는 `매우 중요하다`, `주목할 만하다`, `시사하는 바가 크다`

평가 표현을 지울 때 근거 문장까지 삭제하지 않는다. 구체적 근거를 새로 만들어 대신 넣지도 않는다.

## 문맥을 보고 고칠 문제

### 가능 표현

`~할 수 있다`는 반복된다는 이유만으로 단언형으로 바꾸지 않는다.

- 능력·논리적 가능성·연구의 적용 범위를 나타내면 보존한다.
- 단순한 군더더기이며 명제가 이미 확정된 사실이면 간결화할 수 있다.
- 판단이 어렵다면 보존한다.

### 헤징과 인식 양태

`~로 보인다`, `~로 판단된다`, `시사한다`, `가능성이 있다`, `~로 해석할 수 있다`는 증거 수준을 표시할 수 있다.

- 결과 절과 논의 절에서는 원문의 확신 강도를 고정한다.
- `시사한다`를 `입증한다`로 올리거나 `입증한다`를 `시사한다`로 낮추지 않는다.
- 중첩된 완곡 표현은 하나로 줄일 수 있지만 남은 표현의 강도는 원문과 같아야 한다.

### 수동태와 무생물 주어

- 방법 절에서 절차나 측정 대상을 전면에 두는 수동태는 허용한다.
- 행위자나 책임 주체가 중요한 윤리·정책·사례 분석에서는 주체가 사라지지 않게 한다.
- `분석되었다`를 `연구자가 분석했다`로 바꿀 때 원문이 그 행위자를 실제로 명시하거나 확실히 함의하는지 확인한다.

### 영어 용어와 괄호 병기

- 학회·학문 분야의 표준 용어, 기호, 모델명은 보존한다.
- 정의된 약어는 첫 등장과 이후 용례의 일관성을 유지한다.
- 한국어와 영어 병기를 줄일 때에도 인용·정의·용어 구별 기능이 사라지지 않아야 한다.
- 번역어가 분야마다 다른 경우 임의로 번역하지 않는다.

### 구조와 열거

- 연구문제, 가설, 절차, 변수, 결과의 번호 체계는 보존한다.
- 병렬 구조는 논리적 대응을 드러내면 유지한다.
- 장식적인 `첫째·둘째·셋째`만 문장 흐름에 맞게 줄인다.
- 표·그림을 산문으로 바꾸거나 산문을 임의로 표·불릿으로 바꾸지 않는다.

### 접속사와 결론 표지

`따라서`, `그러므로`, `반면`, `한편`은 학술 논증의 관계 표지일 수 있다. 반복 횟수가 아니라 실제 논리 관계와 위치를 기준으로 판단한다. 삭제 후 관계가 모호해지면 보존한다.

## 절별 기준

### 초록

- 연구 목적, 방법, 핵심 결과, 결론의 순서와 비중을 유지한다.
- 글자 수를 줄일 때 결과의 수치나 제한 조건을 먼저 희생하지 않는다.
- 배경 설명을 줄이는 편집은 사용자가 분량 축소를 요청했을 때만 한다.

### 서론·선행연구

- 인용이 어느 주장까지 뒷받침하는지 범위를 바꾸지 않는다.
- 연구 공백을 과장하는 `최초`, `전무하다`, `유일하다`를 새로 넣지 않는다.
- 여러 연구의 입장을 합치거나 대비 관계를 새로 만들지 않는다.

### 방법

- 재현 가능성에 필요한 절차, 순서, 도구, 매개변수, 포함·제외 기준을 보존한다.
- 시제와 수행 주체를 바꿀 때 실제 연구 수행 관계가 달라지지 않게 한다.

### 결과

- 해석이나 가치 판단을 새로 넣지 않는다.
- 유의성, 방향, 크기, 집단명, 표·그림 참조를 고정한다.
- `차이가 있었다`와 `유의한 차이가 있었다`를 서로 바꾸지 않는다.

### 논의·결론

- 관찰, 해석, 추론, 권고를 서로 다른 층위로 유지한다.
- 상관을 인과로, 가능성을 예측으로, 제한적 결과를 일반 법칙으로 바꾸지 않는다.
- 한계와 예외를 간결화하더라도 삭제하지 않는다.

## 최종 충실성 감사

윤문 후 원문과 결과를 대조해 다음을 확인한다.

1. 모든 인용 표지와 참조 대상이 남아 있는가.
2. 수치·단위·기호·범위·부호가 글자 단위로 일치하는가.
3. 부정, 조건, 예외, 비교 방향과 인과 방향이 같은가.
4. 주장마다 확신과 불확실성의 정도가 같은가.
5. 전문용어·약어·고유명사가 임의로 치환되지 않았는가.
6. 원문에 없던 사실, 근거, 출처, 평가, 행위자가 추가되지 않았는가.
7. 원문의 절 구조와 상호 참조가 정상적으로 작동하는가.
8. 문장이 자연스러워졌지만 학술적 격식과 분야 관례는 유지되는가.

하나라도 확신할 수 없으면 해당 수정만 롤백하고 검토 필요 항목으로 남긴다.
