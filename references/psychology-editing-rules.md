# 심리학 원고 윤문 규칙

심리학 분야의 과제, 연구보고서, 학위논문과 학술 원고를 윤문할 때 이 문서를 적용한다. 사용자가 제시한 학과·학교·학회·투고처 양식이 있으면 그 지침을 우선하며, 별도 지침이 없을 때에도 특정 판본의 APA 양식을 임의로 강제하지 않는다.

## 연구설계와 주장 수준

- 실험·준실험·상관·횡단·종단 설계와 피험자 간·피험자 내·혼합 설계의 구분을 보존한다.
- 무작위 표집과 무작위 할당, 조작과 측정, 예측과 설명, 매개와 조절을 서로 바꾸지 않는다.
- 상관관계나 횡단 자료의 서술을 인과관계로 강화하지 않는다. 원문이 설계보다 강한 인과 표현을 사용한 것으로 보이면 자동 수정하지 말고 `검토 필요`에 표시한다.
- 유의하지 않은 결과를 `효과가 없다`고 단정하거나 `경향이 있다`로 바꾸지 않는다.
- `경향`, `경향성`, `준유의`, `marginally significant`와 같은 표현은 사전에 정한 기준이나 적용할 양식이 확인되지 않으면 정당화하지 말고 `검토 필요`에 표시한다.
- 연구가 관찰한 결과, 저자의 해석, 임상적 함의와 실천적 권고를 서로 다른 층위로 유지한다.

## 구성개념·척도·임상 용어

- 구성개념, 조작적 정의, 측정변수와 잠재변수의 구분을 보존한다. 유사해 보이는 심리학 용어를 동의어로 치환하지 않는다.
- 검사·척도의 정식 명칭, 번역판, 버전, 하위척도, 문항 수, 응답 범위, 채점 방향과 절단점을 그대로 둔다.
- 신뢰도와 타당도, 증상과 진단, 선별검사 결과와 임상적 진단을 혼용하지 않는다.
- 원문에 없는 진단, 병인, 치료 효과나 임상적 판단을 추가하지 않는다.
- 선별척도 점수만 제시된 경우 이를 장애나 질환의 진단으로 확정하지 않는다. 원문이 두 층위를 혼용하면 핵심 술어를 자동으로 바꾸지 말고 필요한 진단 근거를 `검토 필요`에 알린다.
- 참여자·내담자·환자·연구대상자 등 원문의 역할 명칭을 임의로 통일하지 않는다. 낙인 가능성이 있는 표현은 의미와 인용 범위를 바꾸지 않는 대안을 제안하되, 직접 인용과 당사자의 자기명명은 보존한다.
- 질적 연구에서는 참여자 진술, 연구자의 해석, 코드·범주·주제를 구분하고 직접 인용을 요약문이나 계량적 주장으로 바꾸지 않는다.

## 통계 보고

다음 항목은 글자 단위로 대조한다.

- 표본 크기와 집단별 표본 수, 제외 사례, 결측치 처리
- 평균, 표준편차, 표준오차, 중앙값, 범위와 백분율
- 검정통계량, 자유도, 정확한 유의확률, 신뢰구간과 방향
- 효과크기, 회귀계수, 상관계수, 승산비와 모형 적합도
- 신뢰도·일치도 계수, 보정 방식, 공변량과 비교 기준집단

통계 기호의 서체·띄어쓰기·소수점 표기는 사용자가 지정한 양식에 맞춰 정리할 수 있지만 값, 부호, 첨자, 자유도와 부등호는 바꾸지 않는다. 원문에 통계값이 누락되었거나 본문과 표가 충돌하면 값을 추측하지 말고 `검토 필요`에 표시한다.

`N`, `n`, `M`, `SD`, `SE`, `t`, `F`, `χ²`, `r`, `β`, `OR`, `CI`, `p`와 효과크기 기호는 서로 대체하지 않는다. 같은 통계량처럼 보여도 원문이 사용한 기호와 대소문자를 보존한다.

## 절별 판단

### 방법

- 참여자 모집, 포함·제외 기준, 보상, 윤리 심의, 동의 절차를 축약하지 않는다.
- 독립변수·종속변수·공변량, 조건과 집단, 처치 순서와 측정 시점을 보존한다.
- 척도의 번안·타당화 여부와 자료 전처리·분석 절차를 새로 추정하지 않는다.

### 결과

- 결과와 해석을 분리하고, 방향·크기·유의성·비교 대상을 고정한다.
- 연구가 보고하지 않은 사후검정, 효과크기, 임상적 유의성이나 기제를 추가하지 않는다.
- `유의하다`를 일상적 의미의 `중요하다`로, 통계적 유의성을 임상적 중요성으로 바꾸지 않는다.

### 논의와 결론

- 표본과 설계가 허용하는 일반화 범위, 대안 설명과 원문의 한계를 보존한다.
- 가능성·시사점·추정을 사실이나 확정적 기제로 강화하지 않는다.
- 임상적 적용이나 정책적 권고는 원문에 근거가 있을 때만 유지하며 새로 만들지 않는다.

## 인용과 형식

- 저자명-연도 인용, `et al.` 또는 한국어 표기, 괄호의 범위와 복수 문헌의 순서를 임의로 바꾸지 않는다.
- 참고문헌의 서지정보, DOI와 척도 출처를 추측해 보충하지 않는다.
- 통계 표기나 참고문헌 형식의 교정을 요청받은 경우에도 적용할 양식과 판본이 확인되지 않으면 내용은 보존하고 형식 문제만 알린다.

## 심리학 충실성 점검

윤문 후 다음을 추가로 확인한다.

1. 연구설계의 유형과 표집·할당 방식이 그대로인가.
2. 구성개념, 변수, 척도, 집단과 측정 시점이 바뀌지 않았는가.
3. 모든 통계값과 비교 방향이 원문과 일치하는가.
4. 통계적 유의성, 실제적 중요성과 임상적 유의성이 혼동되지 않았는가.
5. 상관·예측·인과의 강도와 일반화 범위가 유지되었는가.
6. 증상, 선별 결과와 진단이 구분되어 있는가.
7. 참여자에 관한 표현이 정확하며 불필요하게 낙인화되지 않았는가.

## 검토 필요 출력

심리학적 의미에 영향을 주어 자동 수정하지 않은 문장은 원문 일부를 인용해 식별하고, `인과 해석`, `비유의 결과 해석`, `선별검사-진단 혼용`, `통계 보고`, `참여자 표현`처럼 문제 유형과 보류 사유를 함께 적는다. 원문에 없는 설계·통계·진단 근거를 가정한 수정 문장은 제시하지 않는다.
